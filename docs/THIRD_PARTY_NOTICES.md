# Third-party notices

NEAT Portal uses open-source libraries and bundled third-party assets.
Dependency manifests and lockfiles identify package names and versions.
Retain the license and copyright notices supplied with those packages/assets
when distributing the application.

The web application uses Next.js, React, TipTap, DOMPurify and other listed
dependencies. Some material-style widgets, HTML sanitization behavior and editor
styling are based on publicly available library implementations; their source
attribution comments remain in place. Those notices describe component origins,
not a runtime dependency on another local project.

The API uses Express, Knex, mysql2 and the other dependencies listed in its
manifest. Static theme assets retain their embedded third-party notices.
This documentation does not assert exclusive authorship of third-party code,
grant additional rights or replace any dependency's license.
